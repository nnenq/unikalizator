# Помощник канала: из TikTok на YouTube

Переносит **ваши** видео из TikTok на русский YouTube-канал про теории и загадки:

1. **Скачивает** новые видео из вашего профиля TikTok — без водяного знака, вместе с русскими автосубтитрами, если они есть.
2. **Готовит** их для YouTube Shorts: 1080×1920, H.264/AAC, громкость по стандарту YouTube. Горизонтальные ролики ставятся на размытый фон, а не на чёрные полосы.
3. **Пишет** название, описание и теги на русском. Если подключён Claude, он смотрит на подпись, субтитры и кадры из видео; без него текст собирается из подписи TikTok по правилам.
4. **Загружает** на YouTube, сразу или по расписанию. Можно не подключать API и загружать вручную: для каждого видео готов файл и текст, который остаётся скопировать.

Помощник запоминает, что уже сделано (`data/state.json`), поэтому при повторном запуске берёт только новые видео.

## Установка (Windows)

1. Поставьте **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/). При установке отметьте галочку *Add python.exe to PATH*.
2. Поставьте **ffmpeg**: откройте PowerShell и выполните
   ```
   winget install Gyan.FFmpeg
   ```
   После этого закройте и снова откройте PowerShell.
3. Скачайте этот репозиторий (*Code → Download ZIP*) и распакуйте. Откройте PowerShell в этой папке и выполните:
   ```
   py -m pip install -r requirements.txt
   py -m tt2yt init
   ```
   Программа спросит ваш ник в TikTok и создаст файл `config.toml`. Откройте его в Блокноте и при желании поправьте настройки: тему канала, теги, подпись под видео.

На macOS и Linux всё так же, только вместо `py` пишется `python3`, а ffmpeg ставится через `brew install ffmpeg` или `apt install ffmpeg`.

## Первый запуск

```
py -m tt2yt run --no-upload
```

Помощник скачает последние видео, подготовит их и напишет описания. Результат лежит в `data\videos\<номер видео>\`:

- `youtube.mp4` — готовое видео;
- `youtube.txt` — название, описание и теги.

Посмотрите, что получилось. Этот текст можно скопировать в YouTube Studio при ручной загрузке, а можно отредактировать файл: при загрузке через API возьмётся ваш вариант.

Дальше достаточно запускать `py -m tt2yt run` или дважды щёлкнуть **run.bat**.

## Описания с помощью ИИ (Claude)

Без ИИ название берётся из первой фразы подписи в TikTok. С Claude получается гораздо лучше: он смотрит кадры и субтитры, пишет цепляющее название, описание с хэштегами и поисковые теги, и не повторяет недавние названия канала.

1. Получите ключ API на [console.anthropic.com](https://console.anthropic.com/) (раздел *API Keys*) и пополните баланс. Одно видео обходится примерно в несколько центов.
2. Сохраните ключ в Windows:
   ```
   setx ANTHROPIC_API_KEY "sk-ant-..."
   ```
   Затем закройте и снова откройте PowerShell.

Тема канала и стиль задаются в `config.toml`, раздел `[meta]`. Чтобы переписать описание для конкретных видео, выполните `py -m tt2yt describe --redo <ID> <ID>`.

## Подключение YouTube для автозагрузки

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и создайте проект.
2. *APIs & Services → Library*: найдите **YouTube Data API v3** и нажмите *Enable*.
3. *APIs & Services → OAuth consent screen*: тип *External*, заполните название. В *Test users* добавьте почту Google-аккаунта, к которому привязан канал.
4. *APIs & Services → Credentials → Create credentials → OAuth client ID*, тип **Desktop app**. Скачайте JSON, переименуйте в `client_secret.json` и положите в папку помощника.
5. Запустите `py -m tt2yt upload`. Откроется браузер: выберите аккаунт канала и разрешите доступ. Доступ сохранится в `token.json`.

**Важные ограничения YouTube API:**

- Пока проект Google не прошёл проверку (*audit*), YouTube **оставляет все видео, загруженные через API, приватными**. Их можно открыть в YouTube Studio: выделите видео → *Изменить → Доступ → Открытый*. Чтобы снять ограничение, подайте заявку на проверку через [форму YouTube API Services](https://support.google.com/youtube/contact/yt_api_form), это бесплатно. Расписание (`schedule = true`) заработает только после проверки.
- В тестовом режиме Google просит заново войти в аккаунт примерно раз в неделю. Помощник сам откроет браузер, когда это понадобится.
- Дневной лимит — около 6 загрузок на проект. Помощник остановится при его исчерпании и продолжит при следующем запуске.

Если возиться с API не хочется, загружайте вручную: `run --no-upload` готовит всё, что нужно.

## Команды

| Команда | Что делает |
|---|---|
| `py -m tt2yt run` | всё сразу: скачать → подготовить → описать → загрузить |
| `py -m tt2yt run --no-upload` | то же, но без загрузки на YouTube |
| `py -m tt2yt status` | список видео и их состояние (`--all` — все) |
| `py -m tt2yt fetch` | только скачать новые видео из профиля |
| `py -m tt2yt fetch --url <ссылка>` | скачать конкретное видео (`--url` можно повторять) |
| `py -m tt2yt fetch --links links.txt` | скачать по списку ссылок из файла |
| `py -m tt2yt add видео.mp4 --caption "тема"` | добавить видео с компьютера |
| `py -m tt2yt prepare` | только подготовить видео |
| `py -m tt2yt describe` | только написать описания (`--no-ai` — без ИИ) |
| `py -m tt2yt upload` | только загрузить (`--dry-run` — показать, что будет загружено) |
| `py -m tt2yt skip <ID>` | не переносить это видео |
| `py -m tt2yt retry` | повторить видео, на которых была ошибка |

Почти все команды принимают `--limit N`, чтобы обработать не больше N видео.

## Если TikTok не отдаёт список видео

TikTok иногда блокирует автоматический просмотр профиля. Что можно сделать:

- В `config.toml` укажите `cookies_from_browser = "firefox"` (или `chrome`, `edge`, `opera`, `brave`) — браузер, в котором вы вошли в TikTok. Chrome и Edge на время запуска лучше закрыть.
- Или скачивайте по ссылкам: в приложении TikTok нажмите *Поделиться → Копировать ссылку*, сложите ссылки в `links.txt` по одной на строку и запустите `py -m tt2yt fetch --links links.txt`.
- Обновите загрузчик: `py -m pip install -U "yt-dlp[default,curl-cffi]"`. TikTok часто меняет сайт, и свежая версия обычно снова работает.

## Автозапуск каждый день

Откройте *Планировщик заданий Windows → Создать простую задачу → Ежедневно → Запустить программу* и выберите `run.bat` из папки помощника.

## Советы для канала

- Видео с водяным знаком TikTok YouTube продвигает хуже. Помощник скачивает версию без него.
- Если в ролике звучит популярная музыка из библиотеки TikTok, на YouTube на него может прийти жалоба Content ID. Такие видео лучше пропустить (`skip`) или перезалить с другим звуком.
- Теории лучше подавать как версии, а не как факты. ИИ так и пишет: у YouTube строгие правила о дезинформации, и это бережёт канал от ограничений.
- Если в видео есть реалистичные кадры, созданные ИИ, при публикации отметьте в YouTube Studio пункт об изменённом или синтетическом контенте.

## Где что лежит

```
config.toml          настройки (не публикуется в git)
client_secret.json   ключ Google (не публикуется)
token.json           доступ к каналу (не публикуется)
data/state.json      учёт всех видео — можно открыть и поправить
data/videos/<ID>/    source.mp4 — исходник, youtube.mp4 — готовое видео, youtube.txt — текст
```
